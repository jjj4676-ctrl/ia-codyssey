\# 개발 워크스테이션 구축 미션



\## 1. 프로젝트 개요



이 저장소는 터미널, Docker, Git/GitHub를 사용하여 개발 워크스테이션을 구축하고 검증한 과정을 기록한 프로젝트입니다.



주요 목표:



\- 터미널 기본 명령어 실습

\- 파일 및 디렉토리 권한 실습

\- Docker 설치 및 기본 명령어 점검

\- Dockerfile 기반 웹 서버 컨테이너 실행

\- 포트 매핑, 바인드 마운트, Docker 볼륨 검증

\- Git/GitHub를 통한 버전 관리 및 제출
